# Jellyfin IPTV-org

Плагин Jellyfin 10.11, который превращает каталог [iptv-org](https://github.com/iptv-org/iptv)
в каналы Live TV с фильтром по категориям и телегидом.

## Как это работает

```
iptv-org JSON API ──► плагин (фильтры, категории, 18+) ──► playlist.m3u ──► M3U-тюнер Jellyfin
guides.json + XMLTV-источники ──► плагин (только ваши каналы) ──► guide.xml ──► XMLTV-гид Jellyfin
```

* **Каталог.** Раз в сутки плагин скачивает `channels`, `feeds`, `streams`, `categories`,
  `logos`, `regions`, `guides` из iptv-org API (с проверкой ETag — неизменившиеся файлы
  не скачиваются заново).
* **Плейлист.** По одному потоку на канал и фид (без пометок «Geo-blocked»/«Not 24/7» и
  с лучшим качеством в приоритете). Каналы нумеруются блоками по категориям;
  `group-title` — категория на русском; `tvg-id` = id iptv-org (`Канал.ru` или `Канал.ru@Фид`).
* **Категории.** Канал с несколькими категориями попадает в первую отмеченную.
  «Все» или «ни одной» означает все категории, включая новые.
* **Телегид.** Для каналов плейлиста плагин находит файлы гида из `guides.json` и читает их
  по очереди (сначала покрывающие больше ваших каналов). Следующий файл заполняет только
  каналы, для которых предыдущие не дали передач. Файлы обрабатываются потоково, в итоговый
  `guide.xml` попадают только ваши каналы.
* **Live TV.** Плейлист и гид — локальные файлы, которые читают встроенные M3U-тюнер и
  XMLTV-гид Jellyfin. Кнопка «Подключить к Live TV» добавляет оба.

## Установка

1. Панель управления → Плагины → Репозитории → «+»:
   `https://raw.githubusercontent.com/celestelsc21-cpu/jellyfin-plugin-iptvorg/manifest/manifest.json`
2. Каталог → **IPTV-org** → установить, перезапустить сервер.
3. Через ~2 минуты после запуска начнётся первая загрузка каталога
   (или «Обновить каналы сейчас» в настройках плагина).
4. В настройках плагина отметить категории → «Сохранить» → «Подключить к Live TV».
5. «Обновить телегид сейчас» — первая сборка гида.

Файлы (Docker, `/config` — том конфигурации):

| Файл | Путь |
|---|---|
| Плейлист | `/config/data/iptvorg/playlist.m3u` |
| Гид | `/config/data/iptvorg/guide.xml` |
| Кэш каталога | `/config/cache/iptvorg/` |

## Задачи

| Задача | Расписание |
|---|---|
| Обновить каналы IPTV-org | ежедневно 04:37 |
| Обновить телегид IPTV-org | каждые 12 часов и в 05:13 |

## Ограничения

* Jellyfin не группирует каналы Live TV по `group-title`; категории видны по нумерации
  и (опционально) по префиксу в названии.
* Потоки, которым нужны свои Referer/User-Agent, по умолчанию пропускаются: M3U-тюнер
  Jellyfin не передаёт такие заголовки для отдельного канала.
* Источники гида — сторонние серверы-сборщики iptv-org; часть из них бывает недоступна.
  Для каналов без источников гида не будет.
* Фильтры по языку, стране и региону уже есть в конфигурации, но пока без интерфейса.

## Безопасность

* Эндпоинты плагина доступны только администраторам.
* Плагин обращается только к фиксированному адресу iptv-org API и к источникам гида из
  `guides.json`; к адресам локальной сети (в том числе после DNS-резолвинга и редиректов)
  подключение запрещено, размер файла гида ограничен 300 МБ.

Состояние

Загрузка…
«Очистить кэш телегида» удаляет собранный гид, скачанные файлы гида, копию гида в кэше Jellyfin и старые передачи из базы Jellyfin; заново гид не собирается до следующего обновления. «Подключить к Live TV» добавляет тюнер M3U (плейлист плагина) и источник гида XMLTV (гид плагина), если их ещё нет. Задачи плагина и расписание — в «Панель управления → Запланированные задачи → IPTV-org».

Категории

Отметьте категории, которые попадут в плейлист. Если отмечены все или ни одной — берутся все категории, включая новые, которые появятся в iptv-org. Канал с несколькими категориями попадает в первую отмеченную.

Страны и регионы

Страна — откуда вещает канал. Страны и регионы объединяются: канал проходит, если подходит под любую из отмеченных. Ничего не отмечено — без ограничения. Отмеченные показываются первыми.

Языки

Язык вещания канала. Ничего не отмечено — без ограничения.

Несколько потоков у канала

Если выключить, каждый вариант канала (HD, SD, региональный) будет отдельным каналом.

Проверка потоков

Плагин запрашивает только плейлист потока (несколько КБ). Если поток не отвечает, берётся следующий поток того же канала; канал без рабочих потоков в плейлист не попадает. Результаты запоминаются: рабочие перепроверяются раз в сутки, нерабочие — раз в 3 дня.
Больше — быстрее, но выше нагрузка на сеть. Для слабого сервера 4.
Меньше — быстрее отсеиваются «зависшие» ссылки, но могут отсеяться медленные рабочие серверы.

Потоки

Тюнер M3U в Jellyfin не умеет передавать такие заголовки для отдельного канала — эти потоки обычно не работают.
Jellyfin не группирует каналы Live TV по категориям. Каналы и так нумеруются блоками по категориям; префикс делает категорию видимой в названии.
По умолчанию выключено. Ограничение доступа по пользователям появится в следующей версии.

Телегид

Коды языков через запятую, в порядке предпочтения (например, ru, en). По ним выбираются название канала из телегида, название и описание передач (если в гиде есть несколько языков), а также язык описания канала (русский или английский).
Применяется после каждого обновления телегида.
Описание видно на странице канала в Jellyfin. Записывается после встроенного обновления телегида Jellyfin.
По пометкам в названии (пометка убирается из названия): х/ф — «Фильмы», т/с и д/с — «Сериалы», м/ф и м/с — «Детям»; а также по категориям в гиде и категории канала. Номер серии берётся из текста, если он есть.
Передача попадает в «Спорт», только если в её названии одновременно есть вид спорта или турнир (футбол, хоккей, РПЛ, КХЛ, Лига чемпионов…) и признак самой игры (соперники через тире, «матч», «финал», «тур», «гонка», «бой»…), и нет слов вроде «обзор», «новости», «итоги», «студия», «д/ф». Фильмы, сериалы и мультфильмы не учитываются.
Нужна пометка «прямая трансляция» / «прямой эфир» в названии или описании. Действует и на спортивные каналы.
Файлы скачиваются по очереди: сначала те, что покрывают больше ваших каналов; следующие заполняют каналы без программы. Меньше — легче для сервера и сети.
